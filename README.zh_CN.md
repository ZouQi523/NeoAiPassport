# 定时炸弹 — NeoAiPassport

面向 FoloToy AI Passport 的离线倒计时拆弹试验，开发分支为
`feature/countdown-bomb`，直接使用官方固件目录和 BSP。

## 玩法

1. 首页上／下键短按松手后增减 1 分钟；按住约 0.5 秒则只增减 5 分钟，不叠加短按。
   默认 5 分钟，范围为 1–180 分钟。
2. 按确认键开始，按单调时钟截止时间倒计时，以“分钟 : 秒 : 百分之一秒”三段显示，
   例如 `04:31:86`，末段两位，每一格为 10 ms；三组数字等宽居中、等间距排列。
3. 再按确认键进入三线拆弹页，倒计时继续进行。
4. 上键剪红线，下键剪黄线，确认键剪蓝线。每局随机确定唯一正确线，
   在不知道答案时任选一根的成功概率为 1/3。
5. 选对显示拆弹成功，1.8 秒后返回；选错或时间归零同步播放爆炸动画与提供的音效，
   2.4 秒后回到首页，
   保留所选时长，等待再次按确认开始。

每次时长调整只执行一次短按或长按操作。开始和选线在按下时立即响应，松开或按住不会重复触发。
进入拆弹页的那次按键不会同时剪线。断电重启恢复默认 5 分钟。
首页无操作 30 秒后调暗屏幕，倒计时期间保持可见。首页保留“定时炸弹模拟器”标题、计时器、加／减按钮、红色开始图标和电量，不显示单位或操作说明；选错线和超时通过扬声器各播放一次爆炸音效。

## 实现与验证

- `main/bomb_game.*`：独立于硬件的游戏逻辑和开机松键保护。
- `main/bomb_ui.*`：重新设计的 LVGL 界面，不使用 demo 界面外壳。
- `main/bomb_sound.*`：独立任务按队列分块播放爆炸音效。
- `components/bsp/`：复用官方屏幕、ADC 按键、音频和电池驱动，未修改驱动。
- `assets/fonts/`：有许可的中文子集及导出字形、像素检查。
- `tests/bomb_ui/`：在电脑上渲染同一套界面，检查视觉效果。

完整交付记录见[需求、默认规则、测试与固件身份](docs/assets/countdown-bomb.zh_CN.md)。
界面截图是软件渲染预览，不是设备实拍。电脑端测试和编译通过不代表实机验收通过。
此前的 Microphone 项目继续保持停止。

## 构建

阅读 [AGENTS.zh_CN.md](AGENTS.zh_CN.md)、[官方文档](docs/README.zh_CN.md)和
[本机环境记录](docs/assets/readme.zh_CN.md)，使用 **ESP-IDF 5.5.3**。
激活环境后从根目录执行：

```sh
./tools/validate.sh
```

门禁包括仓库检查、导出字库检查、电脑端测试、固件编译、合并镜像校验和匹配的调试归档。
产物为可从 **0x0** 刷写的 `build/FoloToy-AI-Passport-full.bin`。
合并烧写会替换当前应用，并可能重置已有设置；写入前须取得对具体镜像和目标设备的明确授权。

原仓库历史与 `origin` 保持不变，工具、备份和构建产物保持忽略。
不自动提交、推送或发布。
