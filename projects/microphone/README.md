# Microphone

目标：利用 AI Passport 的麦克风，为电脑提供语音输入能力。

## 当前状态

仅预留项目结构，尚未实现音频采集、传输、电脑接入或语音识别，也没有可烧写固件。

设备已经到手并通过 USB 连接电脑。连接成功不能替代音频接口和传输可行性的验证。

## 待确认

1. 产品目标：作为系统可选择的通用麦克风，还是按键触发、将识别文字输入当前窗口的语音打字工具。
2. 音频传输和电脑端接入方式，以及需要支持的操作系统。
3. 是否需要保留设备已有功能，以及设备按键的交互方式。
4. 如需语音识别，采用本地还是远程服务；录音与识别数据如何处理。

这些事项需在实现前明确。当前不选择固件基础，不安装依赖，不接入识别服务。

## 目录

- `firmware/`：预留设备端实现位置。
- `desktop/`：确认需要配套电脑程序后再创建。

实际源码接入时补充构建、运行、测试和实机验收步骤。
